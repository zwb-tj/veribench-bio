## 一、为什么是你在做，不是 AI

我们想回答一个问题：**AI 裁判打分，跟人类专家打分，到底像不像？**

要回答它，必须先有一个"人类怎么打"的参照。这个参照**不能由 AI 生成**——
用同一个 AI 既出题又当参照，等于自己给自己判卷。

所以这里需要一个真人。**你是那个参照。**

| 项目里的说法 | 用人话说 |
|---|---|
| rubric 逐条评分 | 对每一条"评判标准"，判断那段回答做到了没有 |
| 0 / 1 / 2 | 没做到 / 做到一半 / 做到了 |
| 双盲独立标注 | 两个人各自打分，**不许商量** |
| Cohen's κ | 两个人打分的一致程度（扣掉"碰巧一样"之后） |
| 人类天花板 | **两个人之间的一致率**——AI 再准也不可能超过它 |
| 裁判 vs 人类 | AI 和人的一致率，**这才是我们最终要报的数** |

**关于"两位标注者"**：如果你只有一个人，**照样可以先做**——你能得到一个
"AI vs 人类"的真实数字。缺的只是那个分母（人类之间的一致率）。
`ann_B_sheet.md` 是给第二位准备的，**两个人不能看对方的分数**。

## 二、具体怎么做

### 1. 打开标注表

`annotation/pilot/ann_A_sheet.md`

里面是 6 道题。每题下面有 **3 份回答**（标着 `BLIND-weak` / `BLIND-medium` /
`BLIND-strong` —— 这只是三个不同的回答，**编号本身不告诉你哪份好**）。

### 2. 每份回答下面，逐条标准打分

每条标准都给了 `0` / `1` / `2` 三档**具体长什么样**。例如：

```
c1 — 是否指出…最薄弱的环节是「靶组织暴露未被证实」
- 0 完全未提及药物暴露、血浆或心肌 CoQ 水平与疗效归因之间的关系
- 1 提到剂量或递送可能不足，但未把…这一具体结果同抗氧化归因联系起来
- 2 明确指出…说明靶组织暴露未获证实，因而抗氧化机制归因缺少靶点结合证据
- 分数：______  备注：
```

**照着那三档对，看这段回答落在哪一档。**

### 3. 三条最重要的规则

1. **只评回答里确实写了的内容。** 它没写就是没写——**不要替它推断、不要替它补全**。
   这是最容易犯的错。
2. **不要被长度影响。** 写得长不等于写得好；堆术语但没说清，属于没做到。
3. **不确定时选 0 并在备注里写为什么。** 不要为了"看起来合理"选中间档。
   1 分只在**明确部分满足**时才用。

### 4. 填分数

编辑 `ann_A.jsonl`（每行一个评分点）：

```json
{"item_id": "R-0001", "answer_id": "BLIND-weak", "criterion_id": "c1", "score": 1, "annotator": "A", "note": "只提到剂量可能不足，没联系到心肌 CoQ 未显著升高"}
```

- 把 `score` 从 `null` 改成 `0` / `1` / `2`
- `note` 非必填，但 **0 分和 1 分最好写一句依据**
- **不要改** `item_id` / `answer_id` / `criterion_id`

### 5. 填完之后

```bash
cd bio-eval/rubric
python scripts/make_annotation_sheets.py --validate annotation/pilot/ann_A.jsonl
```

它会告诉你还剩几条没填（**不会把漏填静默当成 0**）。填满了就跑：

```bash
python scripts/kappa.py --a annotation/pilot/ann_A.jsonl --b annotation/pilot/ann_B.jsonl
```

## 三、我不确定的地方（照实说）

- **这些回答是 AI 写的，不是真实考生作答。** 三个档位（浅/中/优）也是 AI 按
  "敷衍 / 一般 / 严谨"三种水平写的。所以这个试点测的是
  "**人能不能一致地读这套标准**"，**不是**"标准能不能区分真实考生的水平"。
- **题目是"审稿式"方法学题**（混杂、伪重复、多重比较、结论超出数据）。
  你是湿实验背景，对**实验设计**部分应该有直觉，但有些点偏生物统计。
  **如果你标起来觉得吃力，请直接说** —— 这本身是有价值的结果：
  它回答的是"这套标准对领域科学家可用吗"。
- **我（AI）没有参与打分，也不会替你打分。** 你看到的分数栏是空的，这是刻意的。
